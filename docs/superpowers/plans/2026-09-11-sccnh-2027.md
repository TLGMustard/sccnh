# SCCNH 2027 Volunteer Platform Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a privately published, durable volunteer signup and organizer platform for SCCNH 2027.

**Architecture:** Vinext server components and route handlers run on Cloudflare Workers. A D1-backed repository owns event configuration and volunteer mutations; client components render the public signup and organizer workspaces.

**Tech Stack:** TypeScript, React 19, Vinext, Tailwind CSS 4, Cloudflare D1, Drizzle migrations, OpenAI Sites authentication.

**Spec:** `docs/superpowers/specs/2026-09-11-sccnh-2027-design.md`

## Global Constraints

- Preserve the January 25–27, 2027 Monday–Wednesday cadence.
- Compute availability from occupying signups; never store it.
- Keep volunteer PII out of the public schedule.
- Keep database migrations schema-only and D1-safe.
